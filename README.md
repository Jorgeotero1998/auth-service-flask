# Auth Service (Flask) — ES/EN

## Español

Servicio de autenticación en **Flask** (para demostrar que también manejás Flask además de FastAPI).

### Features
- Login con **JWT access/refresh**
- Endpoint `/me`
- Postgres + SQLAlchemy
- Docker + CI

### Run local

```bash
cp .env.example .env
docker compose up --build
```

- API: `http://localhost:8000/health`
